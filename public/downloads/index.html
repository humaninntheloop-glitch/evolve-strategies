The Reliance Panel desktop app · Version 1.1.0

The Reliance Panel is the desktop version of our capture tool. It files AI Permission Slips from your system tray or menu bar, so you can record AI use without opening a browser. It connects to your Human In The Loop organization with an API key and files the same record as the Chrome extension. Version 1.2.0 adds the HITL Browser, described below: capture AI use in a dedicated browser window, with no Chrome extension at all. The browser bridge and AI session reminders from 1.1.0 are included.

Windows

Download for Windows (portable ZIP, 126 MB)

  1. Download the ZIP and unzip it into a folder you will keep, such as a folder inside Documents. The app runs from this folder, so do not delete it.
  2. Open the folder and run HITL Reliance Panel.
  3. Windows SmartScreen may say the app is unrecognized, because the build is not code signed yet. Click More info, then Run anyway.
  4. When the panel opens, click the gear icon for Settings and paste the API key from your Human In The Loop account (Admin, then API Keys), then save.
  5. To file a Permission Slip, paste the AI output, pick the tool from the dropdown, complete the fields, and press File reliance event.

Closing the window keeps the panel running in your system tray. Right-click the tray icon for Open Panel, Settings, or Quit. The shortcut Ctrl+Shift+H opens the panel as well.

Mac

The Mac app is built on your own Mac from our build kit. It takes about five minutes, and the kit includes a step-by-step sheet.

Download the Mac build kit (ZIP, 1.1 MB)

  1. Download the kit and unzip it.
  2. If you do not have Node.js, install the LTS version from nodejs.org first. If macOS offers to install its developer tools, accept.
  3. Open Terminal, go into the unzipped folder, and run npm install, then npm run dist:mac.
  4. Open the .dmg file in the new dist folder and drag HITL Reliance Panel into Applications.
  5. The first time you open it, right-click the app and choose Open. The build is not signed with an Apple certificate yet, so a double-click may be blocked.
  6. Open Settings with the gear icon, paste your API key, and file the same way as on Windows.

Linux

Download for Linux (AppImage, 112 MB)

  1. Download the AppImage.
  2. Make it executable. Right-click the file, open Properties, then Permissions, and allow executing it as a program. In a terminal, chmod +x does the same job.
  3. Run it, open Settings with the gear icon, and paste your API key.

Capture without the extension: the HITL Browser (new in 1.2.0)

If you cannot or do not want to install the Chrome extension, the panel can watch a browser for you instead. Press Launch on the HITL Browser card in the panel and it opens Chrome in a separate window with a profile of its own. Your everyday Chrome, its history and its logins are not touched.

  1. In the panel, press Launch on the HITL Browser card.
  2. In the browser window that opens, sign in to your AI tools (ChatGPT, Claude, Gemini, Copilot or Perplexity) once. The window remembers your sign-ins for next time.
  3. Chat as normal. Each conversation appears in the panel as a capture marked From the HITL Browser. Click Review, check the slip, and file it.

Only pages on those five AI sites are read, only while the HITL Browser is running, and nothing is filed automatically. Press Stop on the card to end the watch and close that browser window.

Connect the browser bridge

The panel and the Chrome extension work better together. With the bridge connected, every capture the extension makes on ChatGPT, Claude, Gemini, Copilot or Perplexity also appears in the panel, ready to review and file. Nothing files itself. You always review first.

  1. In the panel, open Settings with the gear icon. Under Browser bridge, click Connect the Chrome extension.
  2. In Chrome, open the Reliance Tracker extension's Options page and turn on Send captures to the desktop panel.
  3. Use your AI tools as normal. New captures show up at the top of the panel. Click Review, check the slip, and file it.

The panel can also remind you to file when an AI tool is open on your computer, even outside the browser. That is under Settings, then AI session nudges, and it is on by default. The panel only notices that a tool is open. It never reads what you are doing in it, and you can turn the nudges off any time.

Prefer the browser?

The Reliance Tracker extension is on the Chrome Web Store. Chrome installs it in one click and keeps it updated automatically.
